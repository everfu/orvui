# Development tools

| Directory / module | Responsibility |
| --- | --- |
| `catalog/` | Product catalog, frozen compatibility baselines and API collection |
| `registry/` | Copy-source registry, dependency closure, installation import mapping and public type generation |
| `theme/` | Semantic theme CSS generation |
| `social/` | Editable social image source and export instructions |
| `distribution.ts` | Shared package and registry addresses |

Documentation code, generated metadata, build scripts and browser configuration
live in `apps/docs`. See [the docs README](../apps/docs/README.md) for native Nuxt
commands and resource generation. `tools/` contains only shared workspace tools.
Frozen catalog fixtures are never regenerated by ordinary builds.

`pnpm brand:sync` copies the canonical SVG assets using ordinary file commands.

`pnpm build` generates resources once, then builds the library, declarations and
documentation. `pnpm check` runs the build, type checks and existing unit and
integration tests.

`pnpm package:build` prepares only the library, declarations, theme and registry;
the package's `prepack` hook calls it automatically. Keep local archives in
`artifacts/packages/<version>/` and generated reports in `artifacts/reports/`.

Test organization and runnable commands are documented in `CONTRIBUTING.md`.
Publishing, pushing and deployment require an explicit user request.
