# 应用模板

用 orvui 构建的完整应用模板，打开在线工作空间体验。

<a id="applications"></a>
## 应用工作台

### Dashboard

![Dashboard](https://orvui.efu.me/templates/dashboard/preview.png)

指标、销售趋势、筛选与成员表格，组成一个可交互的数据工作台。

[查看详情](https://orvui.efu.me/templates/dashboard) · [在线预览](https://orvui-template-dashboard.netlify.app)

### Mail

![Mail](https://orvui.efu.me/templates/mail/preview.png)

将文件夹、搜索、邮件列表、阅读和本地撰写整合到一个工作区。

[查看详情](https://orvui.efu.me/templates/mail) · [在线预览](https://orvui-template-mail.netlify.app)

### Chat

![Chat](https://orvui.efu.me/templates/chat/preview.png)

对话、流式响应、工具审核、代码与引用构成完整的本地聊天演示。

[查看详情](https://orvui.efu.me/templates/chat) · [在线预览](https://orvui-template-chat.netlify.app)

### CRM

![CRM](https://orvui.efu.me/templates/crm/preview.png)

组合日期范围、销售漏斗、预测、账户与商机，呈现销售工作台。

[查看详情](https://orvui.efu.me/templates/crm) · [在线预览](https://orvui-template-crm.netlify.app)

### Finances

![Finances](https://orvui.efu.me/templates/finances/preview.png)

通过资产趋势、持仓和交易记录展示财务信息，支持周期和隐私切换。

[查看详情](https://orvui.efu.me/templates/finances) · [在线预览](https://orvui-template-finances.netlify.app)

<a id="choosing-template"></a>
## 选择模板
- **Dashboard**: 适合运营后台、订单管理与团队分析。
- **Mail**: 适合展示完整的邮件整理、阅读与撰写流程。
- **Chat**: 适合 AI 对话、工具审核与知识收藏工作空间。
- **CRM**: 适合客户、商机、联系人与团队跟进管理。
- **Finances**: 适合资产概览、支出分类与交易记录管理。
