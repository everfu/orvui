<a id="overview"></a>
# Dashboard

指标、销售趋势、筛选与成员表格，组成一个可交互的数据工作台。

<a id="template-use-cases"></a>
### 适用场景
适合运营后台、订单管理与团队分析。

<a id="preview"></a>
## 交互预览
[在线预览](https://orvui-template-dashboard.netlify.app?lang=zh)

<a id="template-walkthrough"></a>
### 试一试
1. 切换概览统计周期，观察指标与图表更新。
2. 打开订单，搜索 Northstar 并编辑一条记录；刷新后检查更改。
3. 在追踪中完成任务，并在设置中调整工作空间偏好。

<a id="composition"></a>
## 页面组成
- 概览
- 订单
- 追踪
- 分析
- 设置

<a id="notes"></a>
## 使用说明
支持中英文、明暗模式和十一套配色。演示数据保存在当前浏览器；语言切换保留编辑内容。设置中的重置演示可恢复初始数据。

邮件、AI 回复和财务操作仅更新本地状态。在线演示公开，完整源码仅在私有仓库维护。
