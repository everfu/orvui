<a id="overview"></a>
# Chat

对话、流式响应、工具审核、代码与引用构成完整的本地聊天演示。

<a id="template-use-cases"></a>
### 适用场景
适合 AI 对话、工具审核与知识收藏工作空间。

<a id="preview"></a>
## 交互预览
[在线预览](https://orvui-template-chat.netlify.app?lang=zh)

<a id="template-walkthrough"></a>
### 试一试
1. 从探索选择一个主题，创建对话并观察本地流式回复。
2. 尝试停止、重试，并允许或拒绝工具操作。
3. 收藏一条回复，在资料库找到它；刷新后继续历史对话。

<a id="composition"></a>
## 页面组成
- AI 组件组合
- 历史对话
- 新对话
- 资料库
- 探索

<a id="notes"></a>
## 使用说明
支持中英文、明暗模式和十一套配色。演示数据保存在当前浏览器；语言切换保留编辑内容。设置中的重置演示可恢复初始数据。

邮件、AI 回复和财务操作仅更新本地状态。在线演示公开，完整源码仅在私有仓库维护。
