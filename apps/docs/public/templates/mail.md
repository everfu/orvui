<a id="overview"></a>
# Mail

将文件夹、搜索、邮件列表、阅读和本地撰写整合到一个工作区。

<a id="template-use-cases"></a>
### 适用场景
适合展示完整的邮件整理、阅读与撰写流程。

<a id="preview"></a>
## 交互预览
[在线预览](https://orvui-template-mail.netlify.app?lang=zh)

<a id="template-walkthrough"></a>
### 试一试
1. 打开一封邮件，切换星标或将它归档。
2. 撰写邮件并保存草稿，再从草稿箱继续编辑。
3. 将邮件移到回收站，然后恢复；保存到已发送仅更新演示状态。

<a id="composition"></a>
## 页面组成
- 收件箱
- 星标
- 已发送
- 草稿
- 稍后处理
- 归档
- 垃圾邮件
- 回收站

<a id="notes"></a>
## 使用说明
支持中英文、明暗模式和十一套配色。演示数据保存在当前浏览器；语言切换保留编辑内容。设置中的重置演示可恢复初始数据。

邮件、AI 回复和财务操作仅更新本地状态。在线演示公开，完整源码仅在私有仓库维护。
