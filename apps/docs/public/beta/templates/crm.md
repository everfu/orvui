<a id="overview"></a>
# CRM

组合日期范围、销售漏斗、预测、账户与商机，呈现销售工作台。

<a id="template-use-cases"></a>
### 适用场景
适合客户、商机、联系人与团队跟进管理。

<a id="preview"></a>
## 交互预览
[在线预览](https://orvui-template-crm.netlify.app?lang=zh)

<a id="template-walkthrough"></a>
### 试一试
1. 在客户列表搜索 NVIDIA，打开详情并编辑记录。
2. 通过关联记录查看联系人和商机，切换商机状态。
3. 完成任务、记录会议或笔记，并保存列表筛选。

- 风险客户

<a id="notes"></a>
## 使用说明
支持中英文、明暗模式和十一套配色。演示数据保存在当前浏览器；语言切换保留编辑内容。设置中的重置演示可恢复初始数据。

邮件、AI 回复和财务操作仅更新本地状态。在线演示公开，完整源码仅在私有仓库维护。
