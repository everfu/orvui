<a id="overview"></a>
# Finances

通过资产趋势、持仓和交易记录展示财务信息，支持周期和隐私切换。

<a id="template-use-cases"></a>
### 适用场景
适合资产概览、支出分类与交易记录管理。

<a id="preview"></a>
## 交互预览
[在线预览](https://orvui-template-finances.netlify.app?lang=zh)

<a id="template-walkthrough"></a>
### 试一试
1. 切换概览周期，查看资产趋势和持仓。
2. 打开交易详情，修改本地记录；在支出页面筛选支出。
3. 在设置中隐藏金额，再刷新检查隐私偏好。

<a id="composition"></a>
## 页面组成
- 概览
- 资产组合
- 支出
- 交易记录
- 收益
- 设置

<a id="notes"></a>
## 使用说明
支持中英文、明暗模式和十一套配色。演示数据保存在当前浏览器；语言切换保留编辑内容。设置中的重置演示可恢复初始数据。

邮件、AI 回复和财务操作仅更新本地状态。在线演示公开，完整源码仅在私有仓库维护。
