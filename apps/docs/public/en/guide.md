# Introduction to Vue Web

Build Web interfaces with Vue 3.5 Composition API, original component geometry and interactive motion. Use a local package or complete source to add existing components to your Vue application.


<a id="installation"></a>

## Start installation

Follow the [Web installation guide](/en/docs/installation) for a local package or shadcn-vue. The package is not published to npm; the guide provides the current local packing steps.

<a id="import-components"></a>

## Import components

Package Usage imports per-component @orvui/vue entries. Registry source Usage imports local @/components/orvui/ paths. See [Package installation](/en/docs/installation#package) and [Source setup](/en/docs/installation#source-setup).

<a id="copy-source"></a>

## Own the source

Source installation includes the component, relative helpers, theme and licenses. Use [shadcn-vue](/en/docs/installation#shadcn-vue) to install the complete implementation for local editing.

<a id="state"></a>

## State and composition

Use v-model for forms and v-model:open for overlays. Each component page documents default state, slots and composable parts. Explore the [component catalog](/en/components/motion).

<a id="nuxt"></a>

## SSR and Nuxt

Components are designed for SSR safety. SSR, hydration, browser behavior and visual acceptance are verified separately. A dedicated Nuxt module and auto-imports are deferred.
