# Dashboard

An interactive workspace combining metrics, sales trends, filters and a member table.

<a id="template-use-cases"></a>
### When to use it
For operations, order management and team analytics.

<a id="preview"></a>
## Interactive preview
[Live preview](https://orvui-template-dashboard.netlify.app?lang=en)

<a id="template-walkthrough"></a>
### Try it
1. Change the overview reporting period and inspect the metrics and charts.
2. Open Orders, search for Northstar and edit a record. Refresh to check the saved changes.
3. Complete a task in Tracker and customize workspace preferences in Settings.

<a id="composition"></a>
## Application pages
- Overview
- Orders
- Tracker
- Analytics
- Settings

<a id="notes"></a>
## Usage notes
Supports Chinese, English, light and dark appearance and eleven palettes. Demo data stays in this browser; changing language preserves edits. Reset demo in Settings restores the sample data.

Mail, AI responses and financial actions only update local state. Live demos are public; complete sources are maintained in private repositories.
