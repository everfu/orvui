<a id="overview"></a>
# Finances

Present portfolio trends, holdings and transactions with period and privacy controls.

<a id="template-use-cases"></a>
### When to use it
For portfolio overviews, spending categories and transaction records.

<a id="preview"></a>
## Interactive preview
[Live preview](https://orvui-template-finances.netlify.app?lang=en)

<a id="template-walkthrough"></a>
### Try it
1. Change the overview period and inspect the portfolio trend and holdings.
2. Open a transaction detail, edit the local record and filter expenses in Spending.
3. Hide amounts in Settings, then refresh to check the privacy preference.

<a id="composition"></a>
## Application pages
- Overview
- Portfolio
- Spending
- Transactions
- Earn
- Settings

<a id="notes"></a>
## Usage notes
Supports Chinese, English, light and dark appearance and eleven palettes. Demo data stays in this browser; changing language preserves edits. Reset demo in Settings restores the sample data.

Mail, AI responses and financial actions only update local state. Live demos are public; complete sources are maintained in private repositories.
