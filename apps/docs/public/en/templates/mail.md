<a id="overview"></a>
# Mail

A workspace with folders, search, message lists, reading and local composition.

<a id="template-use-cases"></a>
### When to use it
For complete mail organization, reading and composition workflows.

<a id="preview"></a>
## Interactive preview
[Live preview](https://orvui-template-mail.netlify.app?lang=en)

<a id="template-walkthrough"></a>
### Try it
1. Open a message, toggle its star or archive it.
2. Compose a message, save a draft and continue editing it from Drafts.
3. Move a message to Trash and restore it. Saving to Sent only updates local demo state.

<a id="composition"></a>
## Application pages
- Inbox
- Starred
- Sent
- Drafts
- Snoozed
- Archive
- Spam
- Trash

<a id="notes"></a>
## Usage notes
Supports Chinese, English, light and dark appearance and eleven palettes. Demo data stays in this browser; changing language preserves edits. Reset demo in Settings restores the sample data.

Mail, AI responses and financial actions only update local state. Live demos are public; complete sources are maintained in private repositories.
