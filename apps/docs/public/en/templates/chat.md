# Chat

A local chat composition with conversations, streaming responses, tool approval, code and citations.

<a id="template-use-cases"></a>
### When to use it
For AI conversations, tool review and saved knowledge workspaces.

<a id="preview"></a>
## Interactive preview
[Live preview](https://orvui-template-chat.netlify.app?lang=en)

<a id="template-walkthrough"></a>
### Try it
1. Choose a topic in Explore to create a conversation and watch the local streaming response.
2. Try Stop and Retry, then allow or deny a tool action.
3. Save a response, find it in Library and continue the conversation after a refresh.

<a id="composition"></a>
## Application pages
- AI components showcase
- Conversation history
- New chat
- Library
- Explore

<a id="notes"></a>
## Usage notes
Supports Chinese, English, light and dark appearance and eleven palettes. Demo data stays in this browser; changing language preserves edits. Reset demo in Settings restores the sample data.

Mail, AI responses and financial actions only update local state. Live demos are public; complete sources are maintained in private repositories.
