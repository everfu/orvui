# LLMs.txt

Give your coding assistant an index of orvui documentation to read guides, component APIs and examples on demand.

> Product version: 0.1.1

<a id="files"></a>

## Available files

[/llms.txt](/llms.txt) is a lightweight index of guides, components, templates and the registry. Its links point to Markdown and resources generated by this site.

Guide and component pages provide Copy page and Markdown links. For example, Button has separate Chinese and English files containing the corresponding guidance, APIs and examples.

```text
https://orvui.efu.me/llms.txt
https://orvui.efu.me/components/motion/button.md
https://orvui.efu.me/en/components/motion/button.md
```

<a id="usage"></a>

## Use with your assistant

Provide the index URL to an assistant that can read web content, then describe the components you need. Load only the relevant documents to keep context focused.

```text
Read https://orvui.efu.me/llms.txt and build a settings panel with orvui Button and Popover.
Read their English Markdown first and follow the documented APIs and installation mode.
```

## Choose your integration

Use the index for a few documents, connect [MCP](/en/docs/mcp-server) for source and theme queries, or install [Agent Skills](/en/docs/agent-skills) for component guidance and offline references.
