# orvui 更新记录

这里记录 orvui 的本地开发进展与兼容性变化。当前版本仍在开发，未发布到 npm。

> 产品版本: 0.1.0

## 2026-10-26 — 组件实现更新

<a id="week-2026-10-26"></a>
重建组件运行逻辑与演示，保留现有公开接口。

- **improved** 组件目录和生成资源使用 orvui 产品版本，109 个组件与 72 个注册示例的入口保持兼容。 [Installation](/docs/installation)
- **improved** 共享弹层与主题生成逻辑已重建，11 套配色保持兼容值。 [Themes](/docs/theme)
- **improved** 站点字体改从已安装的 Fontsource 包获取，保留字体自己的许可和文件校验。
