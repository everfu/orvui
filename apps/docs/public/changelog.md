# orvui 更新记录

这里记录 orvui 的版本更新与兼容性变化。组件包已发布到 npm，安装方式见安装指南。

> 产品版本: 0.1.1

## 2026-11-01 — orvui 0.1.1

<a id="week-2026-11-01"></a>
更新 npm 安装指南，新增公开 MCP 与按需加载的组件技能文档。

- **fixed** 纠正已发布组件包的安装说明，默认从 npm 安装，补充从 0.1.0 升级到 0.1.1 与 Nuxt 样式配置。 [Installation](/docs/installation)
- **new** 公开只读 MCP 提供组件文档、源码、样式和主题查询，客户端填写 URL 即可连接。 [MCP](/docs/mcp-server)
- **new** 提供完整 Agent Skills 下载包与中英文组件参考，覆盖 110 个组件和 72 个注册变体。 [Agent Skills](/docs/agent-skills)
- **improved** 组件包、注册表和 AI 资源同步到 0.1.1，保留公开 API、动效、11 套配色与语义主题覆盖行为。

## 2026-10-26 — 组件实现更新

<a id="week-2026-10-26"></a>
重建组件运行逻辑与演示，保留现有公开接口。

- **improved** 组件目录和生成资源使用 orvui 产品版本，109 个组件与 72 个注册示例的入口保持兼容。 [Installation](/docs/installation)
- **improved** 共享弹层与主题生成逻辑已重建，11 套配色保持兼容值。 [Themes](/docs/theme)
- **improved** 站点字体改从已安装的 Fontsource 包获取，保留字体自己的许可和文件校验。
